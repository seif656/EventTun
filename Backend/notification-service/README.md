# Notification Service — espace de travail

Ce dossier est réservé au projet Spring Boot `notification-service`. Il **ne contient pas encore une application exécutable** : le responsable doit la générer puis committer le code sur sa propre branche.

Notification est un service **commun** : tous les membres doivent apporter une contribution identifiable, coordonnée par M5. Aucun stockage persistant n’est imposé en Validation 1.
