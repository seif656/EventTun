# Contrats REST/OpenAPI

Un contrat par service (`user-service.yaml`, `event-service.yaml`, etc.) sera fourni par son responsable. Conventions communes : URI plurielles, JSON camelCase, dates ISO 8601, codes HTTP 200/201/204/400/401/403/404/409/500/503 et erreurs Problem Details.

Les contrats ne prouvent pas qu'un endpoint est fonctionnel : noter clairement le statut de son implémentation.
